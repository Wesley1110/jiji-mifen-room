# 雞雞與米粉的小房間

毛絨雞雞、米粉與熊熊毯毯的互動 3D 小房間，使用 Three.js WebGPU，並提供 WebGL 2 相容模式。

網站：https://wesley1110.github.io/jiji-mifen-room/

此專案是獨立的 GitHub Pages 專案，與 `Wesley1110.github.io` 學術網站分開部署。

## 愛心書桌椅

`storybook-desk-1` 加入已確認的愛心書桌椅。開啟 `?view=desk` 或點選「書桌椅」可近看；`furniture-layout.html` 是可點選的三件家具配置圖。

書桌沿床左側牆面放在床尾一帶，避開熊熊地毯；花朵抽屜櫃預留在房門左側，新花語床頭櫃預留在床頭左側。右側原有床頭櫃完整保留。抽屜櫃目前只有配置規劃，新床頭櫃已完成本機預覽。

書桌由 `storybook-desk.js` 建立可獨立移動的 Three.js 立體物件，再由既有 WebGPU / WebGL 2 場景顯示。兩處愛心為實際鏤空，坐墊有厚度，文具、書頁與花朵都是立體幾何。這次沒有修改 Blender v11 原始檔。

## 操作

- 拖曳環繞、滾輪拉近／拉遠。
- WASD 進入自由飛行並移動，Shift 加速，Q／E 下降／上升。
- 自由飛行時拖曳轉向，滾輪沿視線前後移動。
- 點門把開門，可走入走廊並返回房間。
- 選單可縮小或隱藏；按 M 隱藏／恢復。
- 手機支援觸控及飛行方向按鈕。
- 點「伸出熊掌」或按 F，開啟／收起第一人稱熊掌。每點一下畫面會輕拍兩下；空處與遠處是鏡頭前的短距離空拍，靠近並碰到雞雞或米粉的頭頂、臉頰或身體才會壓動絨毛。手機也可直接點觸，拖曳鏡頭不會誤觸拍擊。連續點擊會依序播放，收起熊掌可取消。
- 熊掌依提供的泰迪熊爪參考圖重製：奶油杏色捲絨、三根厚實圓指與側邊拇指，配上咖啡色圓豆形布料肉球。圓胖前臂的中段加厚、往手腕柔和收口，使用同樣的濃密捲絨；拍擊時掌心轉向玩偶。
- 「靠近雞雞／米粉」會移動到適合輕拍的位置。熊掌開啟時可用滑鼠或單指拖曳轉向，也保留右鍵拖曳，WASD、Shift 與滾輪操作照常使用。

毛絲以局部接觸範圍計算壓低、順毛彎曲及彈簧回復，手掌抵達後才施力；距離過遠或隔著牆時不會觸發。這是適合瀏覽器即時運算的近似物理效果，並非逐根毛髮碰撞或玩偶填充物的完整模擬。收手後毛絲會恢復原狀。

## 驗證

執行 `node tests/fur-contact-state.test.mjs`，檢查不同更新頻率下的施力與回彈、角色之間互不影響、沿手勢移動的接觸範圍，以及無效數值的處理。

執行 `node tests/paw-motion.test.mjs`，檢查每次動作有兩個獨立拍擊、兩下之間會抬起，以及結束後收回。

拍擊以實際繪製的影格推進，短暫低幀率不會直接跳過其中一下。熊掌的細絨與立體捲毛由 GPU 實例化繪製；手臂伸長時補償毛絲長度，維持一致的絨毛厚度。

## 部署與資產

GitHub Pages 使用 `main` 分支的根目錄，`.nojekyll` 保留原始靜態檔案。所有執行所需的程式與模型均包含在此專案中，使用相對路徑支援 `/jiji-mifen-room/` 網址。

模型源自本機 Blender v11 場景；毛絨採網頁即時渲染。毛絲資料分為十個二進位檔，瀏覽器載入後完整重組。原始 Blender 檔、參考圖片與本機歷史備份未包含在此專案。

Three.js 授權見 [vendor/THREE-LICENSE.txt](vendor/THREE-LICENSE.txt)。

## 新左床頭櫃本機預覽

`nightstand-preview-3` 依花語床頭櫃參考圖製作：圓角檜木櫃、花朵把手、格紋蕾絲桌布、布罩檯燈、心形葉植栽、小雞擺飾、花形盤、編織籃與書本。點「左床頭櫃」或開啟 `http://127.0.0.1:4174/?view=nightstand` 查看。右側原有床頭櫃保留；抽屜可點花朵握把開關，檯燈保持固定暖光。新櫃體尚未發布，線上版為已確認的 `storybook-desk-1`。

床頭櫃第二版：最上層換成使用者提供封面的 John H. Cochrane《Asset Pricing, Revised Edition》，製作厚硬殼、印字書脊與細書頁，兩本書錯開角度。燈罩與蝴蝶結加入棉布織紋、細微表面起伏、柔和纖維反光及滾邊縫線。書封原圖保存在 `assets/asset-pricing-cover.png`（來源版位於 `dist/assets/`），其著作權歸原權利人；其他房間原始參考圖未打包。此版仍僅供本機預覽。

床頭櫃第三版：兩本書一起往前緣平移，避開植物；上層厚書仍與下層書錯開。抽屜改成實際中空的木盤、側板、後板、布墊和滑軌，點花朵握把可平滑開關；拖曳不會誤開，手機支援點按，也有鍵盤可用的選單按鈕。`?view=drawer` 或「抽屜玩具」會開啟並近看玩具。

`starter-toy-pack.js` 依提供的「米粉雞雞玩具模型.png」建成獨立 3D 玩具組：藍裙女孩、粉紅米粉、銀色小筆電和奶油雞雞。每件是立體幾何，另有 12,780 根短絨毛、薄透明分格、厚紙板及鏤空吊掛孔。紙卡文字為程式繪製貼圖，未把參考圖片當作平面玩具。`nightstand-drawer.js` 管理開合、滑鼠射線與防誤觸。點擊握把優先於熊掌輕拍；保持原房門互動。

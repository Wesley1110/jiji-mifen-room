# 雞雞與米粉的小房間

毛絨雞雞、米粉與熊熊毯毯的互動 3D 小房間，使用 Three.js WebGPU，並提供 WebGL 2 相容模式。

網站：https://wesley1110.github.io/jiji-mifen-room/

此專案是獨立的 GitHub Pages 專案，與 `Wesley1110.github.io` 學術網站分開部署。

## 操作

- 拖曳環繞、滾輪拉近／拉遠。
- WASD 進入自由飛行並移動，Shift 加速，Q／E 下降／上升。
- 自由飛行時拖曳轉向，滾輪沿視線前後移動。
- 點門把開門，可走入走廊並返回房間。
- 選單可縮小或隱藏；按 M 隱藏／恢復。
- 手機支援觸控及飛行方向按鈕。
- 點「伸出熊掌」或按 F，開啟／收起第一人稱熊掌。靠近後點雞雞或米粉的頭頂、臉頰或身體，每點一次會輕拍兩下；手機也可直接點觸。連續點擊會依序播放，收起熊掌可取消。
- 熊掌為圓潤的奶茶棕色短絨造型，掌心有愛心肉球與四顆圓肉球；拍擊時掌心轉向玩偶。
- 「靠近雞雞／米粉」會移動到適合輕拍的位置。熊掌開啟時可用右鍵拖曳轉向，WASD、Shift 與滾輪操作照常使用。

毛絲以局部接觸範圍計算壓低、順毛彎曲及彈簧回復，手掌抵達後才施力；距離過遠或隔著牆時不會觸發。這是適合瀏覽器即時運算的近似物理效果，並非逐根毛髮碰撞或玩偶填充物的完整模擬。收手後毛絲會恢復原狀。

## 驗證

執行 `node tests/fur-contact-state.test.mjs`，檢查不同更新頻率下的施力與回彈、角色之間互不影響、沿手勢移動的接觸範圍，以及無效數值的處理。

執行 `node tests/paw-motion.test.mjs`，檢查每次動作有兩個獨立拍擊、兩下之間會抬起，以及結束後收回。

## 部署與資產

GitHub Pages 使用 `main` 分支的根目錄，`.nojekyll` 保留原始靜態檔案。所有執行所需的程式與模型均包含在此專案中，使用相對路徑支援 `/jiji-mifen-room/` 網址。

模型源自本機 Blender v11 場景；毛絨採網頁即時渲染。毛絲資料分為十個二進位檔，瀏覽器載入後完整重組。原始 Blender 檔、參考圖片與本機歷史備份未包含在此專案。

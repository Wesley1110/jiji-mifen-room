# 雞雞與米粉的小房間

毛絨雞雞、米粉與熊熊毯毯的互動 3D 小房間，使用 Three.js WebGPU，並提供 WebGL 2 相容模式。

網站：https://wesley1110.github.io/jiji-mifen-room/

此專案是獨立的 GitHub Pages 專案，與 `Wesley1110.github.io` 學術網站分開部署。

## 愛心書桌椅

`storybook-desk-1` 加入已確認的愛心書桌椅。開啟 `?view=desk` 或點選「書桌椅」可近看；`furniture-layout.html` 是可點選的三件家具配置圖。

書桌沿床左側牆面放在床尾一帶，避開熊熊地毯；花朵抽屜櫃預留在房門左側，新花語床頭櫃預留在床頭左側。右側原有床頭櫃完整保留。抽屜櫃目前只有配置規劃，新床頭櫃已發布。

書桌由 `storybook-desk.js` 建立可獨立移動的 Three.js 立體物件，再由既有 WebGPU / WebGL 2 場景顯示。兩處愛心為實際鏤空，坐墊有厚度，文具、書頁與花朵都是立體幾何。這次沒有修改 Blender v11 原始檔。

## 操作

- 拖曳環繞、滾輪拉近／拉遠。
- WASD 進入自由飛行並移動，Shift 加速，Q／E 下降／上升。
- 自由飛行時拖曳轉向，滾輪沿視線前後移動。
- 點門把開門，可走入走廊並返回房間。
- 選單可縮小或隱藏；按 M 隱藏／恢復。
- 手機支援觸控及飛行方向按鈕。
- 點「伸出熊掌」或按 F，開啟／收起第一人稱熊掌。每點一下畫面會輕拍兩下；空處與遠處是鏡頭前的短距離空拍，靠近並碰到雞雞或米粉的頭頂、臉頰或身體才會壓動絨毛。手機也可直接點觸，拖曳鏡頭不會誤觸拍擊。連續點擊會依序播放，收起熊掌可取消。
- 熊掌依提供的泰迪熊爪參考圖重製：奶油杏色捲絨、三根厚實圓指與側邊拇指，配上咖啡色圓豆形布料肉球。圓胖前臂的中段加厚、往手腕柔和收口，使用同樣的濃密捲絨；拍擊時掌心轉向玩偶。
- 「靠近雞雞／米粉」會移動到適合輕拍的位置。熊掌開啟時可用滑鼠或單指拖曳轉向，也保留右鍵拖曳，WASD、Shift 與滾輪操作照常使用。

毛絲以局部接觸範圍計算壓低、順毛彎曲及彈簧回復，手掌抵達後才施力；距離過遠或隔著牆時不會觸發。這是適合瀏覽器即時運算的近似物理效果，並非逐根毛髮碰撞或玩偶填充物的完整模擬。收手後毛絲會恢復原狀。

## 驗證

執行 `node tests/fur-contact-state.test.mjs`，檢查不同更新頻率下的施力與回彈、角色之間互不影響、沿手勢移動的接觸範圍，以及無效數值的處理。

執行 `node tests/paw-motion.test.mjs`，檢查每次動作有兩個獨立拍擊、兩下之間會抬起，以及結束後收回。

拍擊以實際繪製的影格推進，短暫低幀率不會直接跳過其中一下。熊掌的細絨與立體捲毛由 GPU 實例化繪製；手臂伸長時補償毛絲長度，維持一致的絨毛厚度。

## 部署與資產

GitHub Pages 使用 `main` 分支的根目錄，`.nojekyll` 保留原始靜態檔案。所有執行所需的程式與模型均包含在此專案中，使用相對路徑支援 `/jiji-mifen-room/` 網址。

模型源自本機 Blender v11 場景；毛絨採網頁即時渲染。毛絲資料分為十個二進位檔，瀏覽器載入後完整重組。原始 Blender 檔、參考圖片與本機歷史備份未包含在此專案。

Three.js 授權見 [vendor/THREE-LICENSE.txt](vendor/THREE-LICENSE.txt)。

`storybook-dresser.js` 依「可愛粉彩花朵衣櫃擺飾」參考圖建立獨立立體家具，放在右側窗戶旁、靠床尾的牆段，正面朝房間中央。位置為 `[4.37, 0, 5.62]`、朝向 `-X`，窗戶、窗簾及原有左右床頭櫃保持原狀；`furniture-layout.html` 同步更新配置。

房間選單「花朵抽屜櫃」或 `?view=dresser` 可近看，原有拖曳、滾輪和飛行操作保留。此版抽屜為外觀模型；既有左床頭櫃的抽屜互動不變。本次發布使用者確認的 `window-dresser-3`，本機細節檢查頁與原始參考圖片不包含在發布中。

`dresser-companions.js` 建立桌上米粉與紅蘿蔔吊飾，細絨毛沿實際曲面分布並彎曲。紅蘿蔔採短胖輪廓、扇形小布葉與短掛繩，底部由初版的約 1.01 提升至 1.33 場景單位。

## 兔耳愛心衣櫃

`bunny-wardrobe-3` 依使用者提供的童話房間家具圖建立獨立立體衣櫃：連續兔耳頂飾與真正鏤空的愛心、雙扇圓拱凹板門、粉色陶瓷花朵握把、寬底抽屜、波浪裙板及圓腳。木材改為不規則的細長山形木紋、柔和早晚材色差、木孔微表面和低光澤上油質感。上方植栽已移除，換成上下錯開的燕麥色與藕粉色布面收納箱，帶滾邊、縫線、黃銅標籤框及皮革提把。

從床看向房門時位於門的左側，衣櫃面向床；位置 `[1.30, 0, 9.18]`、旋轉 `Math.PI`、整體比例 `.90`。選單「兔耳衣櫃」或 `?view=wardrobe` 可近看。點雙門的花朵把手可一起向外打開 108 度，門內側也有小花把手可關上；拖曳鏡頭不會誤觸，開合途中可反向。原有房門與左床頭櫃抽屜操作保留；第四版本機預覽已將下方抽屜改為可拉出的獨立抽屜，點任一花朵把手可拉開或收回。

內部是實際中空的木櫃、厚底板及棉布軟墊，擺放兩隻大粉色蘿蔔抱枕，沒有衣物。第三版移除眼睛、嘴巴、腮紅與小手，保留蘿蔔繡線、布葉和 86,800 根沿曲面分布的短絨毛。`wardrobe-plush-physics.js` 先用重力、柔性填充體約束和軟墊／櫃側／另一隻抱枕的接觸計算安定姿態，再將表面、葉片、繡線與毛絲同步放到該形狀。一隻橫躺，另一隻斜靠其上，接觸底部輕微壓平，葉片自然彎垂。這是載入時計算的靜態平衡姿態，並非可拖動的即時柔體模擬。

`wardrobe-materials.js` 管理檜木與織布材質；`wardrobe-interaction.js` 負責可見性與遮擋檢查、把手點擊和防誤觸。靜態櫃體與兩片活動門分別合併，保持真正鉸鏈轉動。

`node tests/wardrobe-motion.test.mjs` 驗證外開方向、起終位置、中途反向、低更新率、無效數值與連點。`node tests/wardrobe-plush-physics.test.mjs` 驗證抱枕落定角度、支撐接觸、櫃體邊界、柔軟落地表面與數值有效性。`output/wardrobe-inspect.html` 提供外觀、門板、頂飾及玩偶內部檢查。本次發布使用者確認的第三版衣櫃與無臉蘿蔔抱枕；本機細節檢查頁與原始參考圖不包含在發布中。
